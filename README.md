## Connecthub.ai

Connecthub.ai builds tools that detect errors in financial models that manual review tends to miss. The objective is to make financial review faster and more reliable without compromising the rigour the domain requires.

The work is organised into two tracks:

1. **Core auditing product** — the Model Auditor system and its supporting open-source benchmark.
2. **Reusable interface components** — lightweight front-end building blocks used across product and web surfaces.

### Model Auditor

Model Auditor is a hybrid system that audits financial models in approximately 30 minutes. It combines deterministic Excel parsing — which handles model structure and formula tracing — with selective AI reasoning applied only where judgement is required. This keeps results predictable and auditable while reserving AI for the parts of the task that genuinely benefit from it.

Status: in active development.

## Engineering Approach

- **Correctness over coverage.** Deterministic checks are the foundation; AI is applied only where it measurably improves outcomes.
- **Domain-grounded design.** Tools are built around real finance-operations workflows and controls.
- **Verifiable claims.** Detection performance is measured openly through ModelAuditBench rather than asserted.
- **Composable components.** Small, well-scoped modules are preferred over large, tightly coupled systems.
